# Projeto de Integracao SQL/Excel
Um projeto para treinar métodos de integração de SQL Server com o Microsoft Excel utilizando o banco de dados AdventureWorksDW2014 com o propósito de criar tabelas e dashboards interativos.

# Resultados:
Com a criação da view "VENDAS_INTERNET" foi possível filtrar os dados desejados do banco de dados "AdventureWorksDW2014" e então, utilizando a ferramenta SQL Server Import and Export do SQL Server, foi criado um arquivo .xlsx, assim permitindo a utilização desses dados para criar os seguintes gráficos:

- Gráfico de barras comparando a receita total pelo custo total de vendas em cada país
- Gráfico de pizza comparando a razão total de vendas de cada categoria de produtos
- Gráfico de pizza comparando a razão total de vendas por gênero dos clientes
- Gráfico de barras comparando vendas de produtos totais por cada país

# Tecnologias utilizadas:
SQL Server: Ferramenta de programação

Excel: Criação de listas e gráficos
